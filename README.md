 Zomato Dataset Exploratory Data Analysis (EDA)

This project performs an in-depth **Exploratory Data Analysis (EDA) on the **Zomato dataset** to uncover insights about restaurant trends, ratings, pricing, and cuisines.

Key Steps
- Cleaned and handled missing data  
- Analyzed restaurant types, locations, ratings, and average costs  
- Visualized relationships between features using Matplotlib and Seaborn  

Tools Used
Python | Pandas | NumPy | Matplotlib | Seaborn  

Key Insights
- Online order availability strongly influences restaurant popularity  
- Restaurants with higher ratings generally have moderate pricing  
- North Indian and Chinese cuisines are among the most common  
- Bangalore restaurant counts
